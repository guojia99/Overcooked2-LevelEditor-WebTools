# Web 致命鬼魂（web_killer_ghost_01）冒烟测试

依赖：CustomStub ≥ **3.10.2**、关卡集导出含 **commonW4**；巡游/城堡样式需 bundle297，幽灵厨师需 **bundle351**。

## 静态触杀

1. 打开测试关卡，核心层放置 `web_killer_ghost_01`，写回并 Play。
2. 确认包装根下生成 DLC07 鬼魂 child；走近触碰应 **Hit 重生**（非落水特效）。
3. 右键切换「鬼魂样式」（巡游 / 城堡 / 厨师）写回后，Play 期 child 模型应变化。
4. 右键调「触碰半径」写回后，碰撞范围应随之变化。

## 动画组移动触杀

1. 动画层新建组，将鬼魂实例加为成员，配置 `move` 路点并 loop。
2. 写回后 Play：鬼魂沿轨迹移动，触碰仍致死；击杀盒与模型同步移动。

## 联机（Host + Client）

1. 导出关卡集，真机/模拟器 Host 进图，Client 加入。
2. Client 触碰移动中的鬼魂应重生；仅服务端判定（无重复击杀异常）。

## 负例

- 取消「触碰击杀玩家」后写回：贴近不应死亡。
- 未装 CustomStub 或 requires 版本过低：物件可能无击杀（仅装饰壳）。

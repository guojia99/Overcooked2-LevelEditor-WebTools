# 09 · 前端主题系统

> 目录：`layout-editor/web/src/theme/`、`web/src/ui/views/`、`web/src/styles/`
> 一句话定位：为 Web 前端 UI 外壳（顶栏、侧栏、弹窗、管理页等）提供四套可切换主题，通过「统一底座 + ViewFn 修正 + CSS Token」三层架构实现；**不改** 2D 画布绘制与 3D 场景材质。
> 返回 [00-架构总览.md](00-架构总览.md)

---

## 1. 架构概览

```
┌─────────────────────────────────────────────────────────┐
│  页面 TS（levels.ts / modals.ts / nav.ts …）              │
│       ↓ 调用 ui/views/button.ts 等渲染函数               │
├─────────────────────────────────────────────────────────┤
│  统一底座（ui/views/）                                   │
│    cancelBtnHtml / primaryBtnHtml / mBtnHtml …           │
│    → 生成默认 class + data 属性                          │
├─────────────────────────────────────────────────────────┤
│  主题 ViewFn 层（theme/themes/*.ts）                      │
│    publicCancelBtnViewFn / publicPrimaryBtnViewFn …      │
│    → 修正 className / attrs（不改 HTML 结构）             │
├─────────────────────────────────────────────────────────┤
│  CSS Token 层（styles/tokens.css）                        │
│    [data-theme="pink"] { --ui-accent: #E75098; … }       │
│    style.css / recipeList.css 使用 var(--ui-*)           │
└─────────────────────────────────────────────────────────┘
```

**排除区域**（主题系统不触及）：

| 区域 | 原因 |
|---|---|
| `#canvas` 2D 绘制 | Canvas API 由 `render.ts` / `itemColors.ts` / `floorColors.ts` 控制 |
| `#canvas3d` / Three.js | `scene3d/materials.ts` 等 3D 材质独立 |
| 关卡 `BG_THEMES` | 游戏内容主题，非 UI 外壳 |

**纳入主题**：顶栏、工具栏、左右侧栏、弹窗、管理页、画布上的 DOM 浮层（`#item-detail`、`#ctx-menu`）。

## 2. 四套主题

| ID | 名称 | 底色风格 | 主色 | 特点 |
|---|---|---|---|---|
| `black-gold` | 黑金（默认） | 深色 `#1a1d23` | 金色 `#c9a227` + 行动蓝 `#3d6bf3` | 保持原有编辑器观感 |
| `pink` | 粉红 Q 弹 | 浅色 `#fff8fc` | `#E75098` | 大圆角、粉色柔阴影、hover 微弹 |
| `sky-blue` | 天蓝 | 浅色 `#f5faff` | `#40AEFF` | 清爽浅蓝渐变顶栏 |
| `white` | 纯白 | 浅色 `#ffffff` | 深灰 `#3c4043` | 极简灰阶控件 |

切换入口：顶栏右侧四个色块按钮（`nav.ts` → `themePickerHtml()`）。

持久化：`localStorage` 键 `oc2-ui-theme`。

防闪烁：`index.html` `<head>` 内联脚本在 CSS 加载前设置 `document.documentElement.dataset.theme`。

## 4. ViewFn 命名规范

每个主题可在 `ThemeDefinition` 中提供以下可选修正函数：

| ViewFn | 用途 | 默认 class |
|---|---|---|
| `publicCancelBtnViewFn` | 取消 / 关闭 | `modal-btn` |
| `publicPrimaryBtnViewFn` | 确定 / 保存 | `modal-btn primary` |
| `publicDangerBtnViewFn` | 删除 | `m-btn danger` |
| `publicMBtnViewFn` | 管理页按钮 | `m-btn` |
| `publicSmallBtnViewFn` | 面板小按钮 | `btn-small` |
| `publicChipBtnViewFn` | 菜谱筛选 chip | `rl-chip-btn` |
| `publicLinkBtnViewFn` | 文字链 | `link-btn` |
| `publicNavLinkViewFn` | 顶栏导航 | `topnav-link` |
| `publicModalPanelViewFn` | 弹窗面板 | `modal-panel` |

修正函数签名：`(base: BtnViewModel) => BtnViewModel`，只改 `className` / `attrs`，**不改 HTML 结构**。

## 5. 按钮渲染函数（开发必用）

**新代码禁止手写 `<button class="modal-btn">`**，必须使用 `ui/views/button.ts`：

```typescript
import { cancelBtnHtml, primaryBtnHtml, mBtnHtml, smallBtnHtml } from "./ui/views/button";

// 弹窗 footer
openModal("标题", body, modalFooterBtnsHtml());

// 自定义属性
mBtnHtml("开始导出", "primary", { "data-ok": "", id: "exp-start" });
modalBtnHtml("清空已选", "modal-btn", { id: "rw-clear-all" });
smallBtnHtml("添加", "primary", { id: "btn-add" });
```

| 函数 | 场景 |
|---|---|
| `cancelBtnHtml(label?, attrs?)` | 弹窗取消 |
| `primaryBtnHtml(label?, attrs?)` | 弹窗确定 |
| `modalFooterBtnsHtml()` | 取消 + 确定一对 |
| `mCancelBtnHtml / mPrimaryBtnHtml` | 管理页弹窗 footer（m-btn 风格） |
| `mBtnHtml(label, variant?, attrs?, extraClass?, innerHtml?)` | 管理页通用按钮 |
| `dangerBtnHtml(label, attrs?)` | 删除确认 |
| `smallBtnHtml(label, variant?, attrs?)` | 编辑器面板小按钮 |
| `chipBtnHtml(label, active?, attrs?, extraClass?, innerHtml?)` | 菜谱筛选 |
| `linkBtnHtml(label, attrs?)` | 文字链 |
| `navLinkBtnHtml(label, active?, attrs?)` | 顶栏导航 |
| `modalBtnHtml(label, className?, attrs?)` | 自定义 class 的弹窗按钮 |

## 6. CSS Token 表（核心变量）

定义于 `styles/tokens.css`，各主题通过 `[data-theme="…"]` 覆盖：

| 变量 | 用途 |
|---|---|
| `--ui-bg-page` | 页面底色 |
| `--ui-bg-surface` | 顶栏 / 卡片表面 |
| `--ui-bg-panel` | 左右侧栏 |
| `--ui-bg-toolbar` | 工具栏 / 管理页顶栏 |
| `--ui-bg-modal` | 弹窗面板 |
| `--ui-bg-btn-primary` | 主按钮背景（支持 gradient） |
| `--ui-text` / `--ui-text-muted` | 主 / 次文字色 |
| `--ui-border` / `--ui-border-focus` | 边框 / 聚焦 |
| `--ui-accent` / `--ui-accent-action` | 装饰色 / 行动色 |
| `--ui-radius-sm/md/lg` | 圆角 |
| `--ui-shadow-modal` / `--ui-shadow-btn` | 阴影 |
| `--ui-manage-bg-overlay` | 管理页背景图遮罩 |
| `--ui-palette-card-text` / `--ui-palette-card-text-muted` | 左侧调色板卡片文字 |
| `--ui-scene-item-text` / `--ui-scene-item-hover` | 右侧物品清单文字 / hover |
| `--ui-bg-tab-group` / `--ui-layer-tab-active-bg` | 图层 Tab 组 / 激活态 |
| `--ui-canvas-void-bg` | 2D 画布空白区（非地板层 void，不影响物品配色） |
| `--ui-bg-canvas-stage` | 画布舞台外框 |
| `--ui-panel-collapse-bg` | 侧栏折叠条 |
| `--ui-bg-dock` | 底部编排台 |

浅色主题（粉红 / 天蓝 / 纯白）在 `tokens.css` 中为 `.palette-cat-*` 单独定义实心粉彩卡片底色（`--card-bg` / `--card-color`），保证分类道具卡在浅侧栏上可读。

`style.css` / `recipeList.css` 中 UI 外壳颜色应逐步替换为 `var(--ui-*)`。

## 7. 新增主题开发流程

1. 在 `theme/themes/` 新建 `xxx.ts`，实现 `ThemeDefinition`（id / label / swatch / 各 ViewFn）
2. 在 `styles/tokens.css` 追加 `[data-theme="xxx"] { … }` 变量块
3. 注册到 `theme/registry.ts` 的 `THEMES` 数组
4. 在 `theme/index.ts` 的 `THEME_BOOTSTRAP_SCRIPT` 和 `index.html` 内联脚本中追加合法 ID
5. 顶栏色块选择器自动出现（`listThemes()` 驱动）
6. 目视检查：顶栏 / 弹窗 / 管理页 / 编辑器侧栏；确认 canvas / 3D 未变色
7. `npm run build` 验证

---

## 8. 初始化时序

```
index.html 内联脚本 → dataset.theme（防闪）
        ↓
main.ts import tokens.css → initTheme()（读 localStorage，双保险）
        ↓
navHtml() → themePickerHtml() 渲染色块
        ↓
用户点击 → applyTheme(id) → dataset.theme + localStorage + oc2-theme-change 事件
```

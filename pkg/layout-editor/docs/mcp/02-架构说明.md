# 架构说明

MCP 是前端侧的 AI 适配层，不替代 Unity 后端：

```text
MCP Tool
  -> BridgeClient
  -> Unity LayoutEditorHttpServer
  -> SceneLayoutApplier / LevelAdminApi / SetExporter
```

MCP 只提供关卡编辑器域能力，不提供任意文件、Shell、Git 或游戏运行时控制。

当前实现中的草稿保存在 MCP Server 内存中。Server 重启后草稿失效，因此草稿必须在一个连续的 MCP 会话中完成验证和提交。

底层 Bridge 仍然使用现有 `/api/*` 路由。MCP 通过 `setName`、`levelId`、`assetPath` 和 `instanceId` 组织领域调用，并在写回前增加确认和校验。

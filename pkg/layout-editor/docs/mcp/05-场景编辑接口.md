# 场景编辑接口

## 读取

调用 `oc2_get_scene_layout`，参数：

```json
{ "assetPath": "Assets/LevelSets/tester_web/scenes/level_1.unity" }
```

返回 `LayoutDocument`，包括物品、地板、可行走区域、死亡配置、动画组、开关联动、相机和灯光。

## 草稿编辑

创建草稿：

```json
{ "setName": "tester_web", "levelId": "level_1", "assetPath": "..." }
```

移动物品：

```json
{
  "draftId": "draft-...",
  "operations": [
    { "op": "move_item", "instanceId": "u:123", "position": { "x": 3.6, "y": 0, "z": 4.8 } },
    { "op": "rotate_item", "instanceId": "u:123", "y": 90 }
  ]
}
```

支持的 Patch：`move_item`、`rotate_item`、`delete_item`、`add_item`。`add_item` 必须提供完整的目录物品数据，不能只传一个未经查询的名称。

## 提交

提交前必须调用验证和 diff；提交调用：

```json
{ "draftId": "draft-...", "confirm": true, "snap": 0.01 }
```

写回会触发 Unity 场景保存、依赖处理和伪预制体刷新，预计 5-60 秒。失败后不要盲目重试，先重新读取场景和写回历史。

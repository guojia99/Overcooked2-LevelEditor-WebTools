# 快速开始

## 前置条件

- Unity Editor 已打开本工程。
- Layout Editor Bridge 已启动。
- Bridge 可从当前机器访问 `http://10.211.55.3:8765/api/health`。
- Node.js 18 或更高版本。

只使用静态网页或 HTTP MCP 客户端时不需要 Node.js；直接调用 Unity Bridge 的 `/api/mcp/manifest`、`/api/mcp/tools` 和 `/api/mcp` 即可。

## 启动 MCP

```bash
cd layout-editor/mcp
npm install
npm run build
node dist/server.js
```

MCP 使用 stdio，标准输出只承载 MCP 协议；调试日志不要写 stdout。

## Vite 前端调试

```bash
cd layout-editor/web
VITE_DEV_PROXY_TARGET=http://10.211.55.3:8765 npm run dev
```

当前默认代理已经设置为 `http://10.211.55.3:8765`，环境变量只用于临时切换。

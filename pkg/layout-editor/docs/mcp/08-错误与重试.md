# 错误与重试

统一错误结构：

```json
{
  "ok": false,
  "error": { "code": "BRIDGE_ERROR", "message": "...", "retryable": true },
  "bridge": { "online": false, "url": "http://10.211.55.3:8765" }
}
```

处理建议：

- `BRIDGE_ERROR` 且 `retryable=true`：等待 3 秒后重试健康检查。
- HTML 响应：Unity 正在域重载或 Bridge 与前端版本不一致，不要立即重复写操作。
- `NOT_FOUND`：检查关卡集、关卡和 assetPath，不要猜路径。
- 草稿操作失败：保留原 draft，修正 operation 后再提交。
- 写回超时：先调用场景读取和写回历史，不要直接重复 POST。
- 导出超时：查询导出状态，确认 Unity 是否仍处于 build 阶段。

只有 manifest 中 `safeToRetry=true` 的读操作可以自动重试。写场景和导出默认不可自动重试。

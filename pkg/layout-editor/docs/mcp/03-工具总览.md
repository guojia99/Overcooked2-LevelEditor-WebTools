原生 HTTP MCP 通过 `/api/mcp` 提供 `oc2_commit_scene`、`oc2_start_export` 和 `oc2_get_export_status`；HTTP 客户端应自行轮询导出状态，草稿和 `oc2_wait_export` 仍属于 stdio MCP Server 的进程态能力。

写操作返回 `warnings` 时，AI 必须把告警展示给用户，不得静默忽略。

`LevelInfoSO.dependencies` 只接受 `^bundle[0-9]+$`，大小写敏感，不允许路径、commonW、custom_recipes 或 custom_content（包括本集）。新 HTTP/Web 提交含非法项时整体拒绝；详情/分析会自动清理并保存历史非法项。分析的 required/current/missing/extras 只描述原生包，不能用于生成或过滤共享依赖包的 `bundle_dependencies.txt`。MCP 没有独立手写 dependencies 工具；保存后用详情及依赖分析读回校验。共享包 Edit/Play 加载通过独立引用收集路径完成。

模式、重生边界和原生序列工具的完整参数与守卫见[原生模式接口](10-原生模式接口.md)，支持 stdio 与 Unity HTTP MCP。写操作必须 confirm=true、safeToRetry=false，整次调用建议最多等待 180 秒。部署后须通过在线 tools/list 确认 Unity 已重编译。

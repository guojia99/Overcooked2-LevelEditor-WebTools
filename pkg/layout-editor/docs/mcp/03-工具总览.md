# 工具总览

| 工具 | 类型 | 副作用 | 典型耗时 | 等待方式 |
|---|---|---|---:|---|
| `oc2_editor_health` | 发现 | 只读 | <1 秒 | 直接等待 |
| `oc2_list_level_sets` | 发现 | 只读 | 1-5 秒 | 直接等待 |
| `oc2_list_levels` | 发现 | 只读 | 1-5 秒 | 直接等待 |
| `oc2_get_level_detail` | 关卡 | 只读 | 1-5 秒 | 直接等待 |
| `oc2_get_scene_layout` | 场景 | 只读 | 2-15 秒 | 直接等待 |
| `oc2_get_level_recipe_context` | 菜谱 | 只读 | 2-10 秒 | 直接等待 |
| `oc2_analyze_level_dependencies` | 依赖 | 计算 | 2-10 秒 | 直接等待 |
| `oc2_validate_scene` | 场景 | 计算 | 1-10 秒 | 直接等待 |
| `oc2_create_scene_draft` | 草稿 | 内存草稿 | 2-15 秒 | 直接等待 |
| `oc2_apply_scene_patch` | 草稿 | 内存草稿 | <1 秒 | 直接等待 |
| `oc2_validate_scene_draft` | 草稿 | 计算 | <1 秒 | 直接等待 |
| `oc2_diff_scene_draft` | 草稿 | 计算 | <1 秒 | 直接等待 |
| `oc2_commit_scene_draft` | 写回 | 修改 Unity 场景 | 5-60 秒 | 等待响应 |
| `oc2_start_export` | 导出 | 构建 | 3-30 分钟 | 返回后轮询 |
| `oc2_get_export_status` | 导出 | 只读 | <1 秒 | 每 2 秒 |
| `oc2_wait_export` | 导出 | 等待构建（stdio） | 3-30 分钟 | 内部每 2 秒 |

原生 HTTP MCP 通过 `/api/mcp` 提供 `oc2_commit_scene`、`oc2_start_export` 和 `oc2_get_export_status`；HTTP 客户端应自行轮询导出状态，草稿和 `oc2_wait_export` 仍属于 stdio MCP Server 的进程态能力。

写操作返回 `warnings` 时，AI 必须把告警展示给用户，不得静默忽略。

# 异步任务与导出

## 导出

`oc2_start_export` 不等待构建完成，立即返回 MCP `taskId`、轮询间隔和最大等待时间。必须传 `confirm: true`。

推荐调用：

```text
oc2_start_export(confirm=true)
  -> taskId
  oc2_wait_export(timeoutMs=1800000) // 仅 stdio MCP
  -> done/error
oc2_get_export_status()
```

当前 Unity Bridge 导出状态是全局状态，底层以关卡集名作为状态标识。因此同一时间不要并发启动多个导出任务。

## 时间和轮询

- 普通读取：直接等待，最大 30 秒。
- 场景写回：直接等待，建议最大 120 秒。
- AssetBundle 导出：每 2 秒轮询，最大 30 分钟。
- Unity 域重载：连接暂时返回 HTML 或连接失败属于可恢复状态，应先等待 3 秒再调用健康检查。

原生 HTTP MCP 不在 Unity 主线程内同步阻塞等待，应由 HTTP 客户端每 2 秒调用 `oc2_get_export_status`；`oc2_wait_export` 只由 stdio MCP Server 在其进程内提供。

## 下载

当前首期提供导出状态，但未将二进制 zip 直接作为 MCP tool 返回。AI 可根据 `zipFileName` 调用现有 HTTP 下载地址，或由后续版本增加受控的临时下载文件工具。

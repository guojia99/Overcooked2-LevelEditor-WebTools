# 调用模型

## 资源标识

优先使用：

- `setName`
- `levelId`
- 后端返回的 `sceneAssetPath`
- 场景物品的 `instanceId`
- MCP 返回的 `draftId`

不要自行拼接 `Assets/` 路径、GUID 或 bundle 路径。MCP 当前仍要求场景读取使用后端返回的 `assetPath`，后续版本会增加 `setName + levelId` 的自动解析。

## 统一返回

每次调用都返回：

```json
{
  "ok": true,
  "data": {},
  "operation": { "name": "oc2_get_scene_layout", "kind": "read", "sideEffect": "read" },
  "bridge": { "online": true, "url": "http://10.211.55.3:8765" },
  "timing": { "estimatedMs": 10000, "pollAfterMs": null, "deadlineMs": 30000 }
}
```

## 草稿生命周期

```text
create -> apply patch -> validate -> diff -> commit
```

草稿修改不会写入 Unity。提交必须显式传 `confirm: true`，并且 MCP 会再次校验场景数据。
